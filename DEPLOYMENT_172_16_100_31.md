## 2. Option A: One-Click Push from Your Laptop (Windows / Linux / Mac)

### From Windows (PowerShell):
1. Unzip `SAKEC_TBI_Platform_Server_172_16_100_31.zip`.
2. Open PowerShell inside `sakec_tbi_platform\deploy\` and run:
   ```powershell
   .\push_from_windows.ps1
   ```
3. Enter the `sakecsandbox` password when prompted by `ssh`/`scp`.

### From Linux / macOS:
```bash
cd sakec_tbi_platform/deploy
chmod +x push_from_linux_mac.sh
./push_from_linux_mac.sh
```

## 3. Option B: Direct Manual Deployment on `172.16.100.31`

```bash
# 1. Upload the ZIP file from your machine
scp SAKEC_TBI_Platform_Server_172_16_100_31.zip sakecsandbox@172.16.100.31:/home/sakecsandbox/

# 2. SSH into the SAKEC college server
ssh sakecsandbox@172.16.100.31

# 3. Extract and run the automated deployment script
unzip -o SAKEC_TBI_Platform_Server_172_16_100_31.zip -d /home/sakecsandbox/
mv /home/sakecsandbox/sakec_tbi_platform /home/sakecsandbox/sakec-tbi
cd /home/sakecsandbox/sakec-tbi/deploy
chmod +x *.sh
bash deploy_on_server.sh
```

## 5. Verification & Firewall Check
```bash

# Open port 80 and 8080 if UFW firewall is enabled
sudo ufw allow 80/tcp
sudo ufw allow 8080/tcp

# Verify API locally
curl -s http://127.0.0.1:8080/api/analytics/portfolio
```
Open **`http://172.16.100.31:8080`** (or **`http://172.16.100.31`** via Nginx) on any device connected to the SAKEC campus network.
